# Source boundary

## English

All redistributed programs are independently written source code under the repository's MIT license. The examples are freshly invented synthetic records, not copies of operational records.

No vendor JavaScript bundle, production response, exhibitor/customer list, company profile, workbook, session recording, credentials or private source path is included. The portal adapter documents field names; it does not redistribute a website's implementation or grant rights to that website's data.

API acquisition depends on the user's known endpoints and access. The project contains no universal portal adapter, production login or private business history.

## 中文

发布的程序均为独立编写的源码，按 MIT 许可开放。示例全部重新构造，不是对真实业务记录做匿名化处理。

不包含网站厂商 JavaScript bundle、生产响应、展商或客户名单、企业档案、工作簿、会话记录、凭据或私有路径。适配器只说明字段，不复制网站实现，也不代表获得该网站数据的使用权。

API 采集需要使用者提供已知接口和实际访问权限。项目不含通用网站适配器、生产登录或私人业务历史。
